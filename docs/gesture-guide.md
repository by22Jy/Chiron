# 手势控制开关功能使用指南

## 📖 功能概述

手势控制开关功能允许用户通过特定的手势来启用或禁用手势控制系统，避免在日常使用中意外触发手势操作。

## 🎯 核心特性

### ✌️ VICTORY手势开关
- **控制手势**: ✌️ VICTORY手势 (胜利手势)
- **动作**: 切换手势控制启用/禁用状态
- **冷却时间**: 2秒（防止频繁切换）
- **默认状态**: 启用

### 🎛️ 状态管理
- **实时状态**: 视频预览窗口显示当前控制状态
- **状态持久化**: 后端API存储当前状态
- **前端界面**: Dashboard提供可视化控制和状态显示
- **视觉反馈**: 绿色表示启用，红色表示禁用

## 🚀 使用方法

### 1. 手势切换
1. 确保Agent正在运行并检测手势
2. 做出 ✌️ VICTORY手势（食指和中指竖起，其他手指弯曲）
3. 系统会自动切换手势控制状态
4. 观察视频窗口中的状态指示器变化

### 2. 前端控制
1. 访问前端Dashboard页面 (http://localhost:5173)
2. 找到"手势控制"状态面板
3. 点击"启用控制"或"禁用控制"按钮
4. 或点击"同步状态"按钮获取最新状态

### 3. API控制
```bash
# 获取当前状态
curl -X GET http://localhost:8080/api/monitor/gesture

# 切换控制状态
curl -X POST http://localhost:8080/api/monitor/gesture/control

# 设置特定状态
curl -X POST http://localhost:8080/api/monitor/gesture/control/set \
  -H "Content-Type: application/json" \
  -d '{"enabled": true}'
```

## ⚙️ 配置选项

### Agent配置 (config.yaml)
```yaml
# 手势控制相关配置在video_processor.py中设置
video:
  detection_interval: 0.1  # 手势检测间隔
```

### 可调整参数
- `control_toggle_gesture`: 控制手势类型 (默认: "victory")
- `toggle_cooldown`: 切换冷却时间 (默认: 2.0秒)
- `gesture_control_enabled`: 默认状态 (默认: true)

## 🚨 注意事项

### 使用建议
1. **避免误触**: VICTORY手势相对容易做出，但不太容易在常规操作中误触
2. **状态确认**: 使用前请确认当前控制状态，避免影响正常使用
3. **冷却时间**: 连续切换需要等待2秒冷却时间
4. **摄像头权限**: 确保应用程序有摄像头访问权限

### 故障排除
1. **手势不识别**: 检查光线条件和手势是否标准
2. **状态不同步**: 使用前端"同步状态"按钮刷新
3. **API无响应**: 确认后端服务正常运行
4. **预览窗口问题**: 检查摄像头权限和设备连接

## 🔄 工作流程

### 启动流程
1. 启动后端服务 (端口8080)
2. 启动AI服务 (端口8000) - 可选
3. 启动Agent进行手势检测
4. 启动前端界面 (端口5173)
5. 确认手势控制状态为启用

### 日常使用
1. **正常使用**: 手势控制启用时，所有配置的手势都会触发对应动作
2. **临时禁用**: 做VICTORY手势或使用前端按钮禁用控制
3. **恢复使用**: 再次做VICTORY手势或使用前端按钮启用控制

### 关闭流程
1. Agent会自动保存当前状态
2. 重启后默认恢复到启用状态
3. 可通过API或前端手动设置状态
